# BA775-team-07-project-
Project Overview

This project analyzes competitive League of Legends (LoL) match data across major regions — LCK, LPL, LEC, LCS, and international events (MSI/Worlds).
Our goal: identify regional differences in strategy, gameplay patterns, and win conditions.

Using SQL (Google BigQuery), Tableau, Python, and ERD modeling, we examine:

What metrics correlate the most with winning?
How do map side selections affect win rates across regions?
What is the impact of securing dragons / elder dragons?
Which regions show distinct macro or tempo playstyles?
